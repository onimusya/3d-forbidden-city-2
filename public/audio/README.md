# Audio credits

The atlas ships with a quiet ambient loop and short interface cues. The files are included locally so the experience remains available on GitHub Pages without a third-party audio request.

## Ambient loop

- **Heavenly Loop** by isaiah658
- Source: <https://opengameart.org/content/heavenly-loop>
- License: [CC0 / public domain](https://creativecommons.org/publicdomain/zero/1.0/)

The `.mp3` file is a browser-compatible transcode of the original `.ogg` download. The original Ogg file is kept alongside it.

## Interface sounds

- **Interface Sounds** by Kenney
- Source: <https://kenney.nl/assets/interface-sounds>
- License: [Creative Commons CC0](https://creativecommons.org/publicdomain/zero/1.0/)
- Included cues: `click_001`, `open_001`, `confirmation_001`, and `close_001`.

The included `kenney/License.txt` file is retained from the downloaded pack. The `.mp3` files are browser-compatible transcodes of the included Ogg files.
